# Task 29 – Relationship Analysis Using Scatter Plot

## Internship
**Organization:** Veda Technology  
**Track:** Artificial Intelligence & Machine Learning  
**Task:** Day 29 – Relationship Analysis

## Project Overview
This project focuses on analyzing the relationship between two numerical variables using a scatter plot. The Student Performance Dataset is used to visualize the relationship between mathematics and reading scores.

The project demonstrates how data visualization helps identify patterns, trends, and correlations between numerical variables.

## Objective
- Understand relationships between two numerical variables.
- Create scatter plots using Matplotlib.
- Identify positive, negative, and weak relationships.
- Calculate correlation between variables.
- Interpret the observed patterns.

## Dataset
**Dataset:** Students Performance Dataset

The dataset contains student academic performance information.

**Selected Variables:**
- Math Score
- Reading Score

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Imported the required Python libraries.
2. Loaded the Student Performance Dataset.
3. Explored the dataset using Pandas.
4. Selected two numerical variables.
5. Created a scatter plot.
6. Calculated the correlation coefficient.
7. Analyzed the relationship and identified observations.

## Visualization
A scatter plot was created to analyze the relationship between mathematics and reading scores.

## Key Observations
1. A positive relationship is observed between mathematics and reading scores.
2. Students with higher mathematics scores generally tend to have higher reading scores.
3. Some students show variations in reading scores despite having similar mathematics scores.

## Conclusion
The scatter plot indicates a positive correlation between mathematics and reading scores. This project demonstrates how visualization techniques can help understand relationships between numerical variables and extract meaningful insights from data.

**Note:** Correlation indicates association and does not necessarily imply causation.
